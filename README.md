A home router finally confesses why the movie froze at the best part. This tiny program writes its one-line excuse to `/output/entry.txt` after checking the gate: UTF-8, 1 to 200 characters, not blank, a single line. It then fixes the file mode and reads the line back to prove it landed exactly as written.

## Run it

```sh
node main.ts
```
